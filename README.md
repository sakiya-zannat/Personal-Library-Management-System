# Personal Library Management System

A web-based **Personal Library Management System** designed to demonstrate the implementation and visualization of fundamental Data Structures in C++ and Web Technologies.

This application allows users to perform CRUD-like operations (Insert, Delete, Search, and Display) on book records using five core Data Structures.

---

## 🚀 Features

* **Multiple Data Structure Implementations:**
  * **Sorted Array:** Maintains records in ascending order by Book ID.
  * **Sorted Linked List:** Dynamic node allocation ordered by Book ID.
  * **Stack (LIFO):** Top-driven insertion and deletion.
  * **Queue (FIFO):** First-in, first-out sequence management.
  * **Binary Search Tree (BST):** Efficient searching, dynamic insertion, and in-order traversal (supports both Linked and Array representations).
  
* **Core Operations:**
  * **Insert:** Add books with ID, Title, and Author details.
  * **Delete:** Remove books by ID or pop/dequeue based on structure logic.
  * **Search:** Locate books using optimized search methods (e.g., Binary Search, BST Search).
  * **Display:** View stored records rendered as clean UI cards.

## 📖 Usage Guide

    1. Select Operation: Choose between Insert, Delete, Search, or Display.

    2. Select Data Structure: Choose your preferred structure (Array, Linked List, Stack, Queue, or Tree).

    3. Enter Details: Input the required fields (e.g., Book ID, Title, Author).

    4. Submit: Click Submit Action to execute the operation and view the updated records.
